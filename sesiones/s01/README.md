# Sesión 1 · Encuadre y demo de capacidades

**Módulo:** Encuadre · **Duración:** 3 h

## Contenido

- Presentación del curso: formato, evaluación y el proyecto integrador como hilo
  conductor del semestre.
- Demo en vivo de tres capacidades que el proyecto va a integrar:
  1. **Q&A con un LLM pequeño** — y cómo alucina cuando no sabe.
  2. **RAG sobre un documento** — darle al modelo el contexto que le faltaba.
  3. **Análisis multimodal** — un modelo que *ve* y razona sobre una imagen.
- Conformación de equipos (3–4 personas) y arranque del proyecto: campos 1 y 2
  de la plantilla de definición.
