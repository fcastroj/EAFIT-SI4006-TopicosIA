# Proyecto integrador

El curso se articula alrededor de un único proyecto que crece módulo a módulo,
desarrollado en equipos de 3–4 personas. No es un entregable final aislado: cada
módulo añade una capa al mismo sistema, hasta llegar a una **demo pública
desplegada** en la Sesión 16.

## Primer paso

Define tu proyecto con la plantilla:

- [`plantilla-definicion.md`](plantilla-definicion.md)

En la Sesión 1 solo se exigen los campos 1 (Dominio) y 2 (Usuario + decisión).
El resto se completa para la Sesión 2.

## Cómo crece el proyecto

| Módulo | Sesiones | Qué añade al proyecto |
|:------:|:--------:|-----------------------|
| M1 | S02–S04 | Modelo ajustado al dominio |
| M2 | S05–S06 | Harness de evaluación reutilizable |
| M3 | S07–S08, S10 | Sistema RAG con tool use |
| M4 | S11–S13 | Componente visual integrado |
| M5 | S14–S15 | Demo pública desplegada |
